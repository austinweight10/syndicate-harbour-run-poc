## 1. Race Kits

| Field | Value |
|-------|--------|
| Title | Race Kits |
| Handle | `race-kits` |
| Type | Manual |

**Products (include):**

- Race Tee — Unisex (`race-tee-unisex`)
- Running Shorts (`running-shorts`)
- Performance Socks (`performance-socks`)
- Soft Flask 500 ml (`soft-flask`)

**Do NOT include:** Waterproof Shell Jacket, Half-Zip Midlayer, Kids / Youth Run Tee.

**Why:** Intentional **P1** — Race Kits excludes the waterproof shell / wrong filter so wet-weather shoppers (and agents) hit friction when they expect rain cover in a race kit.

Collection description (optional British English):

> Race-day kit for 5K–half weekends. Tee, shorts, socks, and hydration.
